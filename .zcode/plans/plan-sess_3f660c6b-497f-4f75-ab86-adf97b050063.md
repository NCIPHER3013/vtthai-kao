# แผน: ทำปุ่มปริ้นใบเสร็จให้พิมพ์ออกเครื่อง BTP-S80 จริง (80mm)

## Flow ที่ต้องการ
จบการขายที่ POS → เด้งหน้าต่างใบเสร็จ (mockup เดิม) → กดปุ่ม Print → ใบเสร็จออกจากเครื่องพิมพ์ thermal 80mm ทันที

## การเปลี่ยนแปลงโค้ด (5 ไฟล์, ไม่แตะ DB/settings)

### 1. สร้าง `src/lib/print/receiptTemplate.ts` (ใหม่)
`buildReceiptHTML(order, settings, extras)` — สร้าง HTML ใบเสร็จฉบับเต็มสำหรับกระดาษ 80mm:
- `@page { size: 80mm auto; margin: 0 }`, เนื้อที่พิมพ์กว้าง ~72mm
- ฟอนต์ระบบ (Tahoma/Segoe UI) — ไทยสวยบน Windows
- เนื้อหาครบตาม mockup ปัจจุบัน: ชื่อร้าน, header, เลขออเดอร์, วันที่/เวลา, พนักงาน, ประเภทออเดอร์+โต๊ะ, รายการสินค้า (qty × ชื่อ, modifiers, ราคา takeaway ตาม logic `getItemPrice` เดิม), ยอดรวม/ภาษี/รวมทั้งสิ้น, วิธีชำระ, บัตรของขวัญ, footer

### 2. สร้าง `src/lib/print/printHtml.ts` (ใหม่)
`printHtml(html)` — พิมพ์ผ่าน hidden iframe (สร้าง iframe → เขียน HTML → print → ลบทิ้ง) จอ POS ไม่กระพริบ ไม่ต้องใช้ CSS ซ่อน/แสดงแบบเดิม

### 3. แก้ `src/components/pos/ReceiptModal.tsx`
- คงหน้าต่าง preview บนจอเหมือนเดิม
- ปุ่ม Print เปลี่ยนเป็น `printHtml(buildReceiptHTML(...))` แทน `window.print()` + visibility hack เดิม

### 4. แก้ `src/pages/admin/OrdersPage.tsx`
- ปุ่มปริ้นซ้ำใช้ template เดียวกัน (ตอนนี้มี CSS 80mm ของตัวเองแยกอยู่ — รวมเป็นชุดเดียว)

### 5. สร้าง `docs/PRINTER_SETUP_TH.md` (ใหม่)
คู่มือติดตั้งครั้งเดียวบนเครื่อง POS (ไทย): ลง driver BTP-S80, ตั้งเป็นเครื่องพิมพ์ default, ตั้งขนาดกระดาษ 80mm, สร้าง shortcut Chrome/Edge พร้อม `--kiosk-printing` (กดปุ่มแล้วพิมพ์เลย ไม่มี dialog), วิธีปิด margin/หัว-ท้ายกระดาษถ้าเพี้ยน

## ตรวจสอบ & ส่งมอบ
`npm run lint` + `npm run build` ผ่าน → commit + push (CI deploy ตาม workflow เดิม) → คุณทำ setup บนเครื่อง POS ตามคู่มือครั้งเดียว แล้วทดสอบปริ้นจริง

## ไม่ทำในรอบนี้
Auto-print, เปิดลิ้นชักเงิน, ใบสั่งครัว, local agent, แพ็คแอป/APK
