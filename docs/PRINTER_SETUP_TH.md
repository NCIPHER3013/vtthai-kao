# คู่มือติดตั้งเครื่องพิมพ์ใบเสร็จ BTP-S80 (80mm) — ทำครั้งเดียวต่อเครื่อง POS

หลังทำตามคู่มือนี้จบ การปริ้นใบเสร็จจากหน้า POS (ปุ่ม **Print Receipt** ในหน้าต่างใบเสร็จ และปุ่มปริ้นซ้ำในหน้า Orders) จะออกจากเครื่องพิมพ์ทันที

---

## 1. ลง Driver เครื่องพิมพ์

1. เสียบสาย USB (หัวเหลี่ยม) จากเครื่องพิมพ์เข้าเครื่อง POS แล้วเปิดเครื่องพิมพ์
2. ลง driver **BTP-S80**:
   - ใช้แผ่น CD/USB ที่มาพร้อมเครื่อง หรือ
   - ดาวน์โหลดจากเว็บโรงงานผู้ผลิต (SNBC / New Beiyang): **https://snbc.com.cn/btp-s80** — เลือก "Printer Driver Installer ... Windows" (แบรนด์ Ollio/RPOLIO บนเครื่องคือสติกเกอร์ผู้จำหน่าย ตัวเครื่องเป็น SNBC BTP-S80)
3. ตรวจว่าลงสำเร็จ: เปิด **Settings → Printers & scanners** (กด `Win + I`) ต้องเห็นชื่อเครื่อง เช่น *BTP-S80* ในรายการ

> ถ้าไม่เห็นรายชื่อเครื่อง ให้ถอดสาย USB เสียบใหม่ หรือรีสตาร์ทเครื่อง POS

## 2. ตั้งค่าเครื่องพิมพ์

1. ในหน้า **Printers & scanners** คลิกที่ *BTP-S80* → กด **Set as default** (สำคัญ — โหมดปริ้นเร็วจะส่งงานไปเครื่อง default เสมอ)
2. คลิก **Printing preferences** ของเครื่อง:
   - **Paper size**: เลือก 80mm (หรือ 80 × 297 mm / Roll Paper 80mm แล้วแต่หน้าตา driver)
   - **Orientation**: Portrait
   - ถ้ามีช่อง Margins ตั้งเป็น 0 / None

## 3. ตั้งค่าเบราว์เซอร์ให้ปริ้นเงียบ (ไม่มีหน้าต่างเด้งทุกครั้ง)

ทำกับ Chrome หรือ Edge ตัวที่ใช้เปิดหน้า POS:

1. คลิกขวาที่ shortcut ของเบราว์เซอร์บน Desktop → **Properties**
2. ที่ช่อง **Target** ให้เพิ่ม ` --kiosk-printing` ต่อท้าย (เว้นวรรค 1 ครั้งก่อน `--`) เช่น:

   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing
   ```

3. กด OK แล้ว**ปิดเบราว์เซอร์ทั้งหมด**และเปิดใหม่ด้วย shortcut ตัวนี้

ผล: พอกดปุ่ม Print Receipt ในเว็บ ใบเสร็จจะออกจากเครื่องพิมพ์ทันที ไม่มีหน้าต่าง preview เด้งขึ้นมา

> ถ้าไม่อยากใช้ kiosk-printing ก็ได้ — แค่ต้องกดยืนยันผ่านหน้าต่าง print preview ทุกครั้ง (ครั้งแรกให้เลือกเครื่อง BTP-S80, ตั้ง Margins = None, ปิด Headers and footers — เบราว์เซอร์จะจำค่าไว้)

## 4. ทดสอบ

1. เปิดหน้า POS → ขายของ 1 รายการ → จ่ายเงิน
2. ในหน้าต่างใบเสร็จกดปุ่ม **Print Receipt**
3. ใบเสร็จควรออกจากเครื่องพิมพ์ กว้าง 80mm ตัวอักษรไทย/อังกฤษครบถ้วน
4. ทดสอบปริ้นซ้ำ: หน้า **Admin → Orders** → กด View ที่ออเดอร์ → **Print Receipt**

## 5. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เด้งหน้าต่างเลือกเครื่องพิมพ์ทุกครั้ง | ยังไม่ได้เพิ่ม `--kiosk-printing` หรือเปิดเบราว์เซอร์ไม่ได้ผ่าน shortcut ที่แก้ไว้ / เครื่องพิมพ์ไม่ได้ตั้งเป็น default |
| ปริ้นออกเครื่องพิมพ์อื่น (เช่น PDF) | ตั้ง BTP-S80 เป็น default ใน Printers & scanners |
| ใบเสร็จมีช่องว่างข้าง/หัว-ท้ายเกิน | ใน print preview ตั้ง Margins = None, ปิด Headers and footers |
| ตัวอักษรใหญ่/เล็กผิดสัดส่วน | ใน Printing preferences ของ driver ตั้ง paper size = 80mm |
| ปริ้นแล้วกระดาษไม่ตัด | เป็นการตั้งค่าที่ตัวเครื่อง/driver (auto-cutter) — ดูคู่มือเครื่อง BTP-S80 หรือดึงกระดาษตามรอยตัด |
| ปริ้นไม่ออกเลย | เช็คไฟเครื่องพิมพ์ + สาย USB + ลอง Windows Test Page: Printers & scanners → BTP-S80 → Printer properties → Print Test Page |
